# Prototype Experiments

Use this directory for small, isolated browser prototypes that test one interaction or visual behavior without modifying the canonical full app prototype.

Examples include:

- macOS traffic-light hover glyph alignment;
- a single sheet transition;
- a button/hover treatment;
- an isolated Add User interaction before it is integrated into `../app/`.

Experiments may be temporary, but retain ones that document an approved visual/behavioral decision or are useful for regression comparison. Once an experiment is accepted, integrate the result into `../app/` and treat the full app prototype as the native-implementation reference.
